# brazil_plate

Brazil's licence plates for [`plate_core`](https://pub.dev/packages/plate_core) — the Mercosul plate `ABC1D23` under the blue BRASIL band, in all seven category colours (private, commercial, official, diplomatic, dealer, collector and the black national collector plate), with their themes, alphabets, the series-to-state table and an advisory validator.

```dart
import 'package:plate_core/plate_core.dart';
import 'package:brazil_plate/brazil_plate.dart';

PlateCanvas(
  spec: BrazilPlates.mercosul,
  theme: BrazilThemes.private,
  validator: const BrazilPlateValidator(),
  autoValidate: true,
);
```
